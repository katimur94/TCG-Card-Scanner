# Alte Version (HoloScan 1)

Der Stand vor dem Umbau, unverändert aufbewahrt. Er wird **nicht** veröffentlicht, sondern dient

- dem Browser-Test `e2e/upgrade.spec.ts`, der die alte App startet, mit ihr Karten speichert und dann prüft,
  dass die neue Version alles übernimmt;
- als Vorlage für den Scanner (Kantensuche, Bildsuche, Texterkennung, KI-Leser), der in M2/M3 übertragen wird.

Wenn der neue Scanner fertig ist, bleibt hier nur noch, was der Update-Test braucht.
